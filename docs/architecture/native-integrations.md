## Conventions observed across integrations

- **Lazy `await import("…")` at the call site** for most native modules (file system, sharing, print, media library, document picker, image picker, intent launcher, clipboard in one place). Comments give the reason as keeping Expo Go notices/crashes out of module load (e.g. `src/components/ui/BookingQRModal.tsx`). `expo-notifications` is loaded through a single guarded accessor (`loadNotifications` in `src/lib/notifications/pushDevice.ts`).
- **Errors surface via `Alert.alert`** in almost every native call path (export failed, save failed, permission needed).
- **Permission UX:** camera components render an in-app "Allow / Open Settings" card (`canAskAgain` → `Linking.openSettings`); media-library saves try first and request permission only on failure; calendar requests on demand.
